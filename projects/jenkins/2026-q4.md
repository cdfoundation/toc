# Jenkins Update 2026 Q4

The Jenkins project continued to make progress in software delivery, security, user experience modernization, plugin ecosystem development, and community engagement.

## Core development and releases

Jenkins maintained its regular weekly release cadence, reaching weekly release 2.591 on November 16.
Jenkins LTS 2.580.2 was released on October 28.
Development continued on the redesigned Jenkins user interface, including improvements to the Manage Jenkins experience, dashboards, job pages, build history, and mobile usability.
An important security milestone was reached in the November weekly release, which enabled Content Security Policy protection by default.
Content Security Policy will be enabled by default in the January 2027 Long Term Support release.

A set of [draft Jenkins Enhancement Proposals](https://github.com/jenkinsci/jep/pull/426) have been proposed to allow several Jenkins controllers to run as an active / active high availability cluster with ephemeral home directories and state stored in external services.

The project also continued platform maintenance, including the retirement of Jenkins-provided Windows Server 2019 agent container images in favor of newer supported Windows Server versions.

## Security

Security remained a significant project priority.
Three security advisories were published in September and October, addressing vulnerabilities in Jenkins core, plugins, and update-center infrastructure.
The October advisory addressed multiple high-severity Jenkins core vulnerabilities and was delivered through coordinated weekly and LTS security releases.

The Jenkins Security Team continued working with external researchers and the European Commission-sponsored Jenkins Bug Bounty Program.
The project also published guidance for Jenkins administrators concerning the upstream Java4Shell vulnerability.

## Plugin ecosystem and innovation

The plugin ecosystem continued to evolve.
Notable developments included the ORAS Artifact Manager Plugin, which allows Jenkins build artifacts to be stored in OCI-compliant registries, and the Kubernetes Plugin, which supports dynamically provisioned Kubernetes build agents.

The new Artifact Explorer Plugin introduced a modern interface for browsing and inspecting archived build artifacts, including inline previews, search, and checksum verification.
Community work also demonstrated integration patterns between Jenkins and modern internal developer platforms such as OpenChoreo.

## Community and contributor development

Google Summer of Code 2026 projects reached their final stages, delivering improvements to AI-assisted Jenkins administration, plugin modernization reporting, email notifications, and Jenkins.io.

The AI chatbot projects explored documentation retrieval, build failure diagnosis, plugin dependency analysis, and integration with multiple LLM providers.
The Plugin Modernizer statistics project delivered searchable reports covering 431 plugins and 21 modernization recipes, supported by 303 automated tests.

The Jenkins project also conducted its 2026 Governance Board and Officer election process, with candidate statements published in November.
Contributor engagement continued through virtual community activities and the Jenkins Plugin of the Month series.

## Infrastructure and sustainability

The Jenkins Infrastructure Team continued maintaining CI, release, update-center, and community website infrastructure.
Work included LTS infrastructure updates, new mirror availability, Kubernetes modernization, and improvements to build infrastructure.

Infrastructure sustainability remains an area requiring attention.
DigitalOcean announced the discontinuation of its open-source sponsorship program, and current cloud-credit consumption projections indicate that AWS and Azure sponsored credits may require renewal or replacement during 2027.
The project is working to maintain reliable infrastructure while managing operating costs and identifying sustainable sponsorship arrangements.

## Overall status

Jenkins remains an active and evolving open-source project.
The quarter demonstrated continued investment in security, modernization, compatibility, and the plugin ecosystem, while Google Summer of Code and community initiatives continued to bring new contributors and capabilities into the project.

The primary priorities going forward are completing user experience modernization, maintaining security and release quality, improving plugin ecosystem health, expanding contributor participation, and ensuring sustainable infrastructure funding.
