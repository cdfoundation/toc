# Spinnaker Update

* 2026.3.0 is released with MAJOR improvements and enhancements.  See the [release notes](https://spinnaker.io/changelogs/2026.3.0-changelog/) for more information, but some hightlights:
  * AWS SDK1 is removed
  * New UI's for account management
  * SAML moved to spring config
  * Deprecation announcemnts on multiple tools/configs/resources
  * MCP Server
* Halyard was removed from the codebase and kustomize is now the documented and supported installation method
* Post release, cleanup of the old spinnaker images is about to be applied to purge data.  This should reduce project costs, and keep newer supported images.  GHCR being now the default, GAR will no longer
be supported and images will be removed there after a period of time.

## Adoption updates

No major changes in adoption.  However, statistics [showing spinnaker installation and execution types](https://spinnaker.io/docs/community/statistics/) have been updated and show continued usage and lots of activity.  
REMIDNER:  This data isn't entirely accurate given the data reporting CAN be disabled, and things like versions may not be populated in every installation, and there are some inconsistencies in the data.

## Security updates
[There are critical and high](https://github.com/spinnaker/spinnaker/security/advisories?state=published) vulnerabilities, the most recent of which was published early July.  It's highly recommended to be on the most
recent minor version of a supported release (the most 3 recent releases).

## Infrastructure updates
Automatic image cleanup.  This will be purging old release images - this will be cleaning up almost 10 years of old images as a result.
