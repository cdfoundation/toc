# JayeX Project Update

## Change of name from Jenkins X

The Jenkins X project has officially changed it's name to JayeX. There are still a lot of work to
have the name change permeate the whole project. See our [blog post](https://jayex.io/blog/2026/03/19/jayex/)
or the [CD Foundation Announcement](https://cd.foundation/blog/2026/04/16/announcing-jayex/) for more information.

## Development

Work is ongoing to replace Ingress NGINX with Envoy Proxy as the default ingress controller.

Various improvements have been made to make lighthouse more scalable with the number of
repositories. This includes being more efficeint in the use of the GitHub API and concurrency
support.
